OurAirports data (public domain)

data/airports/airports.tsv is built by tools/gen_airports.py from the OurAirports CSV files (https://ourairports.com/data/),
which the project publishes as public domain. The header of the data file records the SHA-256 of both source files.

check https://ourairports.com/data/ for the current statement.
